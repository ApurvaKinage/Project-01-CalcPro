# Project 01 - CalcPro

## Description

CalcPro is a console-based calculator built while learning Java fundamentals.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Exit Option

## Concepts Learned

- Variables
- User Input (Scanner)
- Conditional Statements (if)
- Arithmetic Operations
- Program Structure

## How to Run

1. Compile:

```bash
javac Main.java
2. Run:

```bash
java Main
```
